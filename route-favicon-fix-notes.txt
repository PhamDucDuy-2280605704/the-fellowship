INSTALL:
Copy the included paths into the project root, preserving folders, and overwrite the existing README.md, src/app/layout.tsx, and src/proxy.ts.
Then run:
  npm run lint
  npm run typecheck
  npm run build

After deployment, open the website and refresh the favicon. Browsers can cache old/missing favicons; if the globe remains, hard-refresh the page or remove and re-add the bookmark after the new deployment is live.

No Supabase schema, credentials, migrations, or role-granting logic are changed. Existing Platform Admin authorization checks remain in place.
